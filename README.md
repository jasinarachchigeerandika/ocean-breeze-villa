# Ocean Breeze Villa – Booking System

## 1. Project Overview

Ocean Breeze Villa is a dynamic web-based villa and room booking system developed for a coastal villa located in Mirissa, Sri Lanka.

The system allows visitors to explore available rooms, check room details, and submit booking requests. The administrator can manage rooms and bookings through an administration dashboard.

## 2. Implemented Features

- View the home page.
- Browse available rooms.
- View room details.
- Register a customer account.
- Login and logout.
- Submit room booking requests.
- View personal bookings.
- Administrator login.
- Manage rooms.
- Manage customer bookings.

## 4. Installation Instructions

1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into the `htdocs` directory.
4. Open phpMyAdmin using `http://localhost/phpmyadmin`.
5. Create the database named `ocean_breeze_villa`.
6. Import the `db_structure.sql` file.
7. Open the project using:

`http://localhost/ocean_breeze_villa/`

## 5. Database Configuration

The system uses a MySQL database named `ocean_breeze_villa`.

Database connection settings are maintained in:

`config/db.php`
